## Semantic difference

These features should not share one undifferentiated “handoff” model:

- **Claude `SendMessage` is inter-session communication**: two independent sessions remain two sessions, and only bounded message content crosses the boundary.
- **Claude teleport is cloud-session continuation in a local CLI**: it changes where an existing cloud session is resumed, with a historically one-way web-to-local entry point.
- **Codex handoff is controlled task-location migration**: one chat plus Git state moves between a local checkout and a matching saved-project remote host/worktree, after explicit destination/branch review.

For Loom, message relay, conversation/session continuation, and authoritative workspace migration therefore need separate contracts. Conflating them would obscure different consent points, transferred-state envelopes, failure modes, and authority boundaries.
